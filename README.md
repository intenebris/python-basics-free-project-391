# Генератор паролей (Python)

[![hexlet-check](https://github.com/intenebris/python-basics-free-project-391/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/intenebris/python-basics-free-project-391/actions)

Приложеие генерирует пароли от простых буквенных до более сложных с цифрами и специальными символами (опционально).

# Генерация паролей
Используйте команду `generate_password(length, seed, use_uppercase, use_digits, use_special)`
* В аргументу функции необходимо задать длину пароля `length`. Это позиционный аргумент и он обязателен 
* Ключ `seed` — целое число от 1 до 2147483646, которое необходимо указать для создания условно случайных комбинаций символов.
* Дополнительно можно использовать именованные аргументы `use_uppercase` (По умолчанию значение True) добавляет прописные буквы, `use_digits`  (По умолчанию значение True) который добавляет цифры `use_special` (По умолчанию значение False) который добавляет специальные символы.

# Проверка паролей
Для проверки сгенерированных паролей или любых других используйте команду `check_password(password)`.

Здесь в качестве аргумента передается пароль ввиде строки. При запуске функции без заданного аргумента будет получен вывод строки `"Некорректные данные"`.

# Запуск приложения
Для запуска приложения используйте команду в терминале:
```
python main.py
```
# Примеры вывода
Для примера и теста используем этот скрипт:
 ```
print("== Генерация паролей ==")
print("буквы и цифры:   ", generate_password(length=12, seed=123))
print("со спецсимволами:", generate_password(length=16, seed=7, use_special=True))

print()
print("== Проверка надёжности ==")
print("abc        ->", check_password("abc"))
print("abcdef1234 ->", check_password("abcdef1234"))
print("Abcdef123! ->", check_password("Abcdef123!"))
 ```
Вывод в терминале должен быть такой:
```
== Генерация паролей ==
буквы и цифры:    5vjehYzZEzZ0
со спецсимволами: X@qzNBCMdbAejoX8

== Проверка надёжности ==
abc        -> Слабый пароль (оценка 1 из 5)
abcdef1234 -> Средний пароль (оценка 3 из 5)
Abcdef123! -> Очень надёжный пароль (оценка 5 из 5)
```
